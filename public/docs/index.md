# OrcaSlicer Calibration Documentation

Welcome to the documentation hub for the OrcaSlicer Calibration Suite. This section consolidates all of the guides, reference material, and DOE (Design of Experiments) resources that support the calibration tools shipped with the application.

Use the navigation sidebar to jump directly to areas of interest:

- **DOE Planner** — methodology, walkthroughs, and statistical reference material that power the planner.
- **Overview** — high-level look at the OrcaSlicer calibration philosophy.
- **Profile Management** — how to organize, migrate, and maintain printer and filament profiles.
- **Calibration Guides** — step-by-step tuning instructions covering first layer, flow rate, pressure advance, temperature towers, and more.

Each page is written in Markdown and rendered inside the app. Math-heavy pages use KaTeX, so LaTeX-style equations should display exactly as they would in the original documentation.

Looking for something specific? The search bar in the main application can take you straight to the relevant calibration tool or guide.
